# Web Window Title (Odoo 14)

Set a custom browser window title for your Odoo instance.

**Price:** Free

## Features

- Custom browser tab/window title via `web.base.title` system parameter
- Settings UI under General Settings → Window → Title
- Demo value included

## Usage

1. Install the module
2. Go to Settings → General Settings → Window → set the **Title**
3. The browser tab title updates accordingly
